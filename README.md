# Skincare Product Sentiment Analysis & Recommendation System

**Graduation Project | King Khalid University**

A web-based skincare analytics and recommendation system developed as a collaborative graduation project by a team of three Information Systems students.

## Project Overview

The system uses Natural Language Processing (NLP) and sentiment analysis to examine customer reviews, identify customer opinions, and support personalized skincare product recommendations.

## Technologies

- **Backend:** Python, Flask
- **Database:** MySQL, SQLAlchemy
- **Sentiment Analysis:** VADER, TextBlob
- **Data Analysis:** Pandas
- **Machine Learning:** Scikit-learn

## Key Features

- Customer review sentiment classification
- Personalized recommendations based on skin type
- Customer feedback analysis
- Sentiment trends and analytical dashboards
- Suspicious review detection using Isolation Forest

## Project Status

Academic team project. Preparing a documented public demonstration and reviewing the codebase for safe publication.
